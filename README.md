# Stelix Team

Площадка цифровых ресурсов: плагины, скрипты, модули, карты, шаблоны и заказы на
разработку. Полноценное веб-приложение: публичный каталог, кабинеты покупателя и
продавца, корзина и оплата, выплаты продавцам, лента чата и уведомлений, а также
полная админ-панель. Встроенный бэкенд в памяти позволяет запускать проект
целиком, без внешних сервисов.

Документация и демо: https://eincode1337.github.io/stelix-team/

## Стек

- Next.js 15 (App Router, Turbopack), React 19, TypeScript
- CSS Modules (дизайн-система лежит в `src/styles/stelix.css`)
- Хранилище данных в памяти на `globalThis`, заполняется из JSON в `src/server/`
- REST API в `/api/*` (около 70 маршрутов), описание в [`docs/API.md`](docs/API.md)
- Локализация: русский (по умолчанию), украинский, английский

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшн:

```bash
npm run build
npm start          # http://localhost:3000
```

Ещё команды: `npm run lint`, `npm run typecheck`.

## Тестовые входы

Нажмите «Войти», введите любую почту, запросите код и введите любой код из
6 символов (буквы или цифры), например `123456`. Роль зависит от почты:

| Почта | Роль | Доступ |
|---|---|---|
| `admin@stelix.team` | AGENT | Полная админ-панель |
| `moderator@stelix.team` | MODERATOR | Разделы модерации |
| любая другая почта | NEWBIE | Обычный пользователь (покупатель и продавец) |

Админ-панель находится на `/admin` и открывается по иконке щита в шапке для
служебных ролей. Данные хранятся в памяти и сбрасываются при перезапуске сервера.

## Локализация

Интерфейс доступен на `ru` / `uk` / `en`. Язык входит в адрес страницы
(`/ru/...`, `/uk/...`, `/en/...`) и переключается в шапке и подвале. Строки лежат
в `src/i18n/messages.ts`.

## Структура проекта

```
src/
  app/            маршруты App Router (страницы и обработчики /api/*)
  components/     интерфейс (shell, каталог, продавец, админка, чат)
  server/         хранилище в памяти, сессии, API-хелперы, начальные данные
  i18n/           движок локалей и словарь строк
  styles/         CSS дизайн-системы
docs/             API.md и openapi.yaml
```

## API

- Справочник по маршрутам: [`docs/API.md`](docs/API.md)
- Контракт OpenAPI 3.1: [`docs/openapi.yaml`](docs/openapi.yaml)

Платёжные вебхуки (16 входящих и 9 выплатных провайдеров) обслуживают два
динамических маршрута, см. `src/app/api/webhooks/README.md`.
