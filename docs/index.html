Площадка цифровых ресурсов

Плагины, скрипты, модули, карты, шаблоны и заказы на разработку. Полноценное веб-приложение на Next.js 15 со встроенным бэкендом: запускается целиком, без внешних сервисов.

Быстрый старт

Node.js 18.18+ или 20+. База данных и ключи не нужны: данные хранятся в памяти и заполняются при запуске.

git clone https://github.com/eincode1337/stelix-team.git
cd stelix-team
npm install
npm run dev        # http://localhost:3000

Продакшн

npm run build
npm start          # http://localhost:3000
Данные лежат в памяти и сбрасываются при перезапуске сервера.

Тестовые входы

Нажмите «Войти», введите любую почту, запросите код и введите любой код из 6 символов, например 123456. Роль зависит от почты.

ПочтаРольДоступ
admin@stelix.teamAGENTПолная админ-панель на /admin
moderator@stelix.teamMODERATORРазделы модерации
любая другая почтаNEWBIEОбычный пользователь: покупатель и продавец
Для служебных аккаунтов админ-панель также открывается по иконке щита в шапке. Код на почту не приходит: в этой сборке подходит любой код из 6 символов.

Возможности

Публичная часть, кабинеты покупателя и продавца, платежи и полная админ-панель.

Каталог

Ресурсы по типам и играм, страницы ресурсов, подписки, поиск и правовые документы.

Покупатель

Корзина, оплата с баланса, покупки, заказы на разработку и лента уведомлений.

Продавец

Кабинет со статистикой, публикация ресурсов (платный, бесплатный, комплект, подписка), выплаты и отчёты.

Админ-панель

Пользователи, роли и доступы, продавцы, заказы, покупки, ресурсы, отзывы, финансы, кассы и настройки.

Платежи

Пополнение баланса и приём вебхуков от 16 входящих и 9 выплатных провайдеров.

Языки

Русский, украинский и английский. Язык входит в адрес страницы и переключается в шапке и подвале.

Структура проекта

src/
  app/            маршруты App Router (страницы и обработчики /api/*)
  components/     интерфейс (shell, каталог, продавец, админка, чат)
  server/         хранилище в памяти, сессии, API-хелперы, начальные данные
  i18n/           движок локалей и словарь строк
  styles/         CSS дизайн-системы
docs/             API.md и openapi.yaml

Документация

  • API.md: справочник по всем маршрутам /api/*
  • openapi.yaml: контракт в формате OpenAPI 3.1
